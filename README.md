# Kashish Katiyar — Developer Portfolio

A responsive, single-page developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `kashish-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Customize before publishing
- Check the email address and social profile URLs in `index.html`.
- Add your GitHub profile URL when ready.
- Verify project descriptions and technology stacks against your actual implementation.
- Add a resume PDF to `assets/` and a download link if you want one.
- Add repository links to project cards only after the repositories are public.

## Publish free with GitHub Pages
1. Create a GitHub repository named `kashish-portfolio`.
2. Upload the contents of this folder (make sure `index.html` is at the repository root).
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

The site uses Google Fonts when internet access is available; system fallbacks are included.
